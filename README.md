温州市滨海高级中学 · 校园墙 —— 内容发布 / 学习专区 / 个人中心 综合平台。纯 PHP + MySQL + Nginx 单体应用，无框架依赖。

## 功能模块

> **板块变更**：树洞 / 论坛 / 问答 已彻底下线，页面、接口、后台模块与数据库表均已移除；`migrate15.sql` 负责清理历史数据（执行前务必备份）。历史更新日志中提及这些板块属当时记录，未改写。

- **校园墙**（首页）：发帖支持图片、点赞（IP 去重）、评论（审核后公开）、不良用语自动替换为等长 `*`；投稿可选分类（寻人 / 寻物 / 求助 / 吐槽 / 其他），首页提供分类筛选与关键词搜索（内容 / 标题 / 昵称，可叠加）
- **🔥 热门速览**（首页首屏常驻小模块）：默认紧凑展示 Top3，一键「展开全部」可看完整 Top10；「🔥 最热」按点赞数实时排名（前三名金 / 银 / 铜），「🕒 最近」按发布时间展示刚上墙的内容；无需登录、无需滚动，访客打开首页即可看见；点条目展开全文，「查看原帖」跨页定位并高亮，点赞 / 删除后自动刷新；榜单为空时模块仍常驻并显示占位提示
- **图片评论**：评论可附 1 张图（jpg / png / gif / webp，≤10MB，服务端自动压缩），支持纯图片评论；评论仍走原有审核流程，后台审核列表可直接预览评论图，删除评论 / 帖子时同步清理图片文件
- **楼中楼回复 + @提醒**：评论可回复，回复按楼层缩进展示并标注被回复者；只做一层（回复某条回复时自动归到所属顶层评论），父评论被删时子回复仍按顶层兜底显示；回复同样需审核，通过后被回复者收到站内消息提醒（自己回复自己不打扰）
- **评论点赞**：每条评论可点赞 / 再点取消，按 IP 去重，访客也能点；未审核评论不可点赞，删除评论时点赞记录由外键级联清理
- **首页排序切换**：筛选栏提供「🆕 最新 / 🔥 最热 / ⭐ 精选」，最热按点赞数降序、精选只看管理员标记的优质内容；切换时重置分页，与分类、搜索条件可叠加，公开接口仍不返回作者 ID 与 IP
- **外观模式（浅色 / 深色 / 自动）**：全站（首页 / 学习专区 / 关于更新 / 个人中心 / 后台）右下角按钮打开「外观模式」菜单三选一；自动模式实时跟随系统主题变化，手动选择后不受系统影响，选择记在浏览器本地并跨标签页同步；支持 `Alt + T` 开关菜单、`Shift + D` 快速翻转、`Esc` 关闭、`↑↓` 选择；深色下卡片、公告条、顶栏、弹窗与文字对比度均单独适配
- **发布与匿名规则**：所有发布入口（校园墙 / 评论 / 学习资料）统一要求登录；未登录时校园墙的发布框与评论区输入框自动隐藏，只显示登录 / 注册入口；发帖与评论各有独立的「匿名」勾选，互不影响，前台只显示「匿名」，后台仍可查看真实账号、昵称、IP；公开接口不返回作者 ID 与 IP，匿名不会被接口泄露；管理员可在后台随时把任意内容 / 评论切换为匿名或不匿名，并可自定义前台显示昵称（溯源字段不变）
- **登录注册**：登录只需图形验证码；注册需图形验证码 + 邀请码。各页面登录 / 注册弹窗均已接入验证码与邀请码
- **内容管理闭环**：登录用户可自助删除自己发布的内容；任何访客可对内容提交举报（按 IP 限频），管理员在后台一键下架或忽略，举报同时汇总进待处理中心
- **我的收藏**：登录用户可在首页卡片或优质专区一键「☆ 收藏 / ★ 已收藏」，个人中心「我的内容 → ⭐ 收藏」集中查看与取消；收藏记录绑定用户与帖子，帖子 / 用户删除时由外键自动级联清理，公开列表仍不返回作者 ID 与 IP
- **优质内容专区**：管理员在后台一键「设优质」，内容自动通过审核并置顶，专区优先展示；取消置顶可随时撤销
- **学习专区**：资料区需登录后查看，支持资料 / 图片 / 其他文件上传与下载、分类浏览，由后台直接管理；顶部「🔗 学习网站直达」是**免登录公开区块**，访客可直接点击管理员发布的网课 / 题库 / 官方平台网址并在新窗口跳转，后台可增删改查、启停、排序、查看点击数，还能上传自定义图标照片（≤2MB，自动裁成方形，无图回退 emoji）
- **个人中心**：资料卡（改昵称 / 改密码）、我的发布（全文展开 / 查看原文）、⭐ 我的收藏、消息通知；首页顶栏常驻「👤 我的」入口
- **关于我们 / 更新修复日志**：独立模块，日志仅由管理员在后台发布，也可在后台编辑、删除
- **内容规范公告**：首次访问弹窗提示，确认后不再重复打扰
- **后台管理**（`/admin`，前台隐藏入口）：12 个导航标签（含「待处理中心」）
  - 内容审核（通过 / 拒绝 / 删除、**编辑文本 / 分类标签 / 匿名状态**，标题可留空，显示具体时间、IP、真实作者与匿名状态；列表可一键切换匿名 / 不匿名）
  - 评论审核（通过 / 拒绝 / 删除、**预览评论图片**、匿名状态切换）
  - 举报处理（查看理由、发帖人账号、下架违规内容 / 忽略，已处理记录留痕）
  - 运营概览（今日发帖 / 评论 / 新用户、近 7 日趋势、待审积压、举报数、热门内容 Top5）
  - 用户管理（创建 / 编辑 / 封禁 / 删除、查看并管理其上传内容、**每账号私享备注**：仅后台可见、前台接口零泄露、独立接口保存）
  - 🔗 免登录链接（学习网站直达：添加 / 编辑 / 启停 / 删除 / 排序 / 点击数 / 图标照片上传，网址仅允许 http / https）
  - 邀请码管理、敏感词词库增删、学习资料文件信息编辑、更新日志管理、优质内容置顶
- **上传与图片**：单张配图 10MB、学习资料 30MB、学习链接图标 2MB；服务端自动高质量压缩（JPEG / WebP / PNG）并校正手机竖拍 EXIF 方向，图标裁成 256×256 居中方形后存 `uploads/linkicons/`；前台统一小缩略图，点开看原图，加载失败自动重试
- **安全**：登录 / 注册图形验证码（GD）、邀请码注册、封禁强退、参数绑定防注入、后台接口鉴权、前后台登录凭据独立存储、公开接口字段脱敏

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | PHP 8.2（PDO / MySQL），单文件 `api.php` 路由 |
| 前端 | 原生 HTML / CSS / JS，多页面 |
| 数据库 | MySQL（`schema.sql` + `migrate*.sql` 增量迁移，幂等） |
| 服务器 | Nginx + php-fpm，Let's Encrypt SSL（ECDSA + RSA 双证书并行，兼容老设备） |

## 快速开始

1. **准备数据库**
   ```bash
   mysql -u root -p biaobai < schema.sql
   for f in migrate.sql migrate2.sql migrate3.sql migrate4.sql migrate5.sql migrate6.sql \
               migrate7.sql migrate8.sql migrate9.sql migrate10.sql migrate11.sql \
               migrate12.sql migrate13.sql migrate14.sql migrate15.sql migrate16.sql migrate17.sql; do
     [ -f "$f" ] && mysql -u root -p biaobai < "$f"
   done
   ```

2. **配置**
   ```bash
   cp config.example.php config.php
   # 编辑 config.php 填入数据库账号密码
   ```

3. **部署**（部署脚本通过环境变量提供 SSH 密码，不入库）
   ```bash
   SSH_PASS='你的root密码' SSH_PORT=10086 ./deploy.sh <服务器IP>
   ```

4. **访问**：前台 `https://<域名>/`，后台 `https://<域名>/admin`

更新修复日志见 [CHANGELOG.md](CHANGELOG.md)，站点内可在「关于 / 更新」模块查看。从旧版本升级需依次执行 `migrate12.sql`～`migrate20.sql`。其中 `migrate15.sql` 会删除已下线板块的数据表，`migrate16.sql` 为评论表增加 `image` 字段并建立热门索引，`migrate17.sql` 增加 `parent_id` / `reply_to` 与 `comment_likes` 表，`migrate18.sql` 为 `users` 增加管理员备注字段，`migrate19.sql` 新建 `study_links` 表，`migrate20.sql` 为学习链接增加 `icon_image` 字段；**执行前务必先备份**（`scripts/backup.sh`），部署脚本会自动检测新增表 / 字段并创建 `uploads/linkicons/` 目录。

## 运维与可靠性

- **备份**：`scripts/backup.sh` 每天 03:30 由 cron 执行，产物在 `/www/backup/campus/`，日志 `/var/log/campus_backup.log`，保留 14 天；每次备份都会做 `gzip -t` 完整性校验
- **恢复**：`scripts/restore.sh <db_YYYYMMDD_HHMMSS.sql.gz> [--yes]`，默认需交互输入 `yes`，并先自动保存一份恢复前快照
- **证书**：ECDSA + RSA 双证书由 Nginx 按客户端能力自动选择；RSA 证书用 `certbot --cert-name bingao-rsa` 独立签发，certbot.timer 自动续期
- **安全头**：HSTS（先设 1 天观察）、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`；后台额外 `no-store`

## 安全说明

- `config.php` 含真实数据库密码，**已在 `.gitignore` 排除**，请勿提交
- `deploy.sh` 的 root 密码通过环境变量 `SSH_PASS` 传入，无硬编码
- 备份脚本从 `/root/.mysql_root` 读取数据库密码，脚本内不含明文；**备份文件含用户数据，仅存服务器本地，请勿外传或提交到公开仓库**
- 上传目录 `uploads/` 已排除，且禁止执行其中的 PHP
- 后台登录凭据使用独立存储键 `bb_admin_token`，前台用户凭据为 `bb_token`，互不干扰
- 匿名仅对前台可见性生效：数据库始终保留 `user_id` / `is_anon` / `ip`，供管理员溯源；公开 `list` / `featured_list` / `hot_rank` / `comments` 已剔除这些字段
